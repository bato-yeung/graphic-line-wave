# graphic-line-wave

## 專案描述
graphic-line-wave 是一個用於生成動態線條波形圖的工具，適合用於視覺化展示或創意設計。此專案提供簡單的設定與高效的渲染效果。

## main.js 的運作
`main.js` 是專案的核心檔案，負責以下功能：
- 初始化畫布並設定繪圖環境。
- 根據使用者的參數生成動態波形。
- 持續更新畫面以實現動畫效果。

### 運作流程
1. 初始化畫布並設定尺寸。
2. 定義波形的參數（如振幅、頻率、顏色）。
3. 使用動畫迴圈不斷繪製波形。

### 各參數說明
- `amplitude`：控制波形的振幅，決定波形的高度。
- `frequency`：控制波形的頻率，決定波形的密集程度。
- `color`：設定波形的顏色。
- `speed`：控制波形的移動速度。
- `canvasWidth` 和 `canvasHeight`：設定畫布的寬度與高度。

### 畫布大小對波形的影響
- 畫布的寬度 (`canvasWidth`) 決定了波形的水平顯示範圍，較大的寬度可以顯示更多的波形週期。
- 畫布的高度 (`canvasHeight`) 決定了波形的垂直顯示空間，較大的高度可以容納更高的振幅。
- 畫布大小的改變會影響波形的整體比例，需根據需求調整相關參數以達到最佳效果。

### 滑鼠位置 (Y 軸) 對波形色調的影響
- 滑鼠的 Y 軸位置會動態影響波形的色調 (hue)。
- 當滑鼠在畫布的頂部時，波形的色調偏向冷色調（如藍色）。
- 當滑鼠在畫布的底部時，波形的色調偏向暖色調（如紅色）。
- 這種互動效果使波形的顏色能夠根據使用者的操作即時變化，增強視覺體驗。

### 使用方式
1. 打開專案目錄中的 `index.html` 文件。
2. 使用瀏覽器直接開啟該文件。
3. 頁面加載後，`main.js` 將自動運行並生成波形圖。
